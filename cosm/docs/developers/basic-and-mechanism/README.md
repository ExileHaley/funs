# Basic & Mechanism

Cosm’s product model is simple to explain and precise on-chain:

1. A token launches onto a **bonding curve** with a chosen quote asset  
2. Traders buy and sell through **CosmPortal** while the curve fills  
3. At a fixed supply milestone, the token **graduates** to DEX liquidity  
4. Trading continues through Portal; tax tokens may keep funding destinations and vaults
