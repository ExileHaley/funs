# Recent Release

## cosm-v0.8.0 — BNB Smart Chain

Cosm’s current public deployment on BSC.

### Highlights for users & builders

- Unified CosmPortal trading for bonding curve and graduated markets  
- Multi-quote launches: BNB, USDT, USDC, USD1, USDX  
- BNB one-click entry into enabled ERC20-quote markets  
- Tax tokens with splitter / dividend modules  
- Six official Cosm Tax Vault strategies via CosmVaultPortal  
- Clear separation: Portal for simple launches, VaultPortal for vault launches

### Compatibility notes

- Prefer CosmVaultPortal when attaching official vaults at launch  
- Wallets/terminals should not invent vault relationships from heuristics
