## Creator journey you should support

1. Choose standard vs tax  
2. Choose quote asset  
3. Optional: choose a vault strategy  
4. Set name / symbol / meta / taxes  
5. Optional first buy  
6. Simulate → launch → share token page  

Keep advanced vanity-salt search behind the scenes; creators should feel a polished form, not a CREATE2 puzzle.
