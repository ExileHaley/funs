## Product principles

1. **Portal is the trade button** — curve and DEX  
2. **Events invent the feed** — then enrich with Portal reads  
3. **Tax and vaults are first-class** — not footnotes  
4. **Quote asset shapes UX** — BNB vs stables vs native one-click
